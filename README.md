# Ant-Feeding-Simulation-NetLogo

# Overview
This project simulates ant foraging behavior using agent based modeling in NetLogo.

# Objective To model ant foraging behavior and observe emergent petterns.

# Tools Technologies used
Agent based modeling
NetLogo

# How to run
Download the NetLogo file
Open the file in NetLogo
Click on display
Then Go

# How it works
Ants search randomly for food
Food source emits signals
Ants follow paths to food and then returns to the nest
